Trois manières de l'utiliser

▶

CLI

Outil global NuGet, pour CI et lint local.

dotnet tool install -g aspx-lint
aspx-lint scan ./MyProject
aspx-lint fix  ./MyProject --dry-run
aspx-lint watch ./MyProject
⌘

Dashboard Web

Single-page HTML servie par AspxLint.Server. Inspection visuelle, drag-drop, command palette (Ctrl+P), find/replace, edit-in-place avec syntax highlighting live, mini-map style VS Code, diff intra-ligne.

▣

App Desktop

Windows WPF + WebView2. Single-instance kill-and-relaunch, file watcher local, drag-drop natif, sans URL bar ni devtools — l'expérience d'une app native.

Sortie CLI multi-format

text JSON SARIF JUnit XML CodeClimate TAP v14

Pour intégration CI : SARIF est uploadé vers GitHub Code Scanning (annotations dans les PRs), CodeClimate est consommé par les Quality Gates Codacy/CodeClimate, JUnit par les agrégateurs de tests classiques.
